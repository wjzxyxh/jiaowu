# TabBar 图标说明

此目录用于存放底部导航栏图标。

## 需要的图标文件

- `home.png` / `home-active.png` - 首页图标
- `calendar.png` / `calendar-active.png` - 日历图标
- `profile.png` / `profile-active.png` - 个人中心图标

## 图标规格

- 尺寸：81px × 81px
- 格式：PNG
- 背景：透明
- 颜色：
  - 未选中：灰色 (#7A7E83)
  - 选中：主题色 (#667eea)

## 图标资源

可以使用以下方式获取图标：

1. 使用 iconfont 图标库
2. 使用 UI 设计工具（如 Figma、Sketch）设计
3. 使用在线图标生成工具

## 临时方案

如果暂时没有图标，可以：

1. 使用纯色占位图
2. 使用 emoji 作为临时图标（需要修改 pages.json 配置）
3. 使用 uni-app 内置图标组件
