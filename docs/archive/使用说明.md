## 系统简介

教务管理系统是一个功能完整的教育机构管理平台，主要用于管理学生、教师、排课、缴费和财务统计等业务。系统采用Web界面，操作简单直观，支持多用户权限管理。

### 主要功能

- ✅ **学生管理**：学生信息管理、状态跟踪
- ✅ **教师管理**：教师信息管理、成本设置
- ✅ **课程管理**：课程配置、价格设置
- ✅ **排课管理**：灵活的排课系统，支持周视图和日历视图
- ✅ **缴费管理**：记录学生缴费，自动计算剩余课时
- ✅ **课时统计**：自动统计学生和教师的课时数据
- ✅ **财务管理**：收支统计、利润分析
- ✅ **用户权限**：基于角色的权限管理系统
- ✅ **操作日志**：完整的操作审计日志
- ✅ **通知提醒**：课时不足提醒、未确认课程提醒

## 安装和启动

### 1. 安装依赖

打开终端，进入项目目录，执行：

```bash
pip install -r requirements.txt
```

或使用 Python 3：

```bash
pip3 install -r requirements.txt
```

### 2. 启动应用

#### 方式一：直接运行

```bash
python3 app.py
```

#### 方式二：使用启动脚本

```bash
bash run.sh
```

### 3. 访问系统

启动成功后，系统会自动显示访问地址，通常为：

- **本地访问**：http://localhost:80 或 http://localhost
- **局域网访问**：http://[服务器IP]:80 或 http://[服务器IP]

**注意**：80端口是HTTP默认端口，访问时可以不输入端口号。如果80端口被占用，可以通过环境变量PORT指定其他端口，或修改app.py中的默认端口配置。

## 登录系统

### 默认管理员账号

首次启动系统后，使用以下默认账号登录：

- **用户名**：`admin`
- **密码**：`admin123`

⚠️ **重要提示**：首次登录后，请立即修改管理员密码！

### 登录步骤

1. 打开浏览器，访问系统地址（如：http://localhost 或 http://localhost:80）
2. 系统会自动跳转到登录页面
3. 输入用户名和密码
4. 点击"登录"按钮

### 用户角色说明

系统支持四种用户角色，不同角色拥有不同的权限：

| 角色 | 说明 | 权限范围 |
|------|------|----------|
| **admin（管理员）** | 系统管理员 | 拥有所有权限，可以管理用户、查看操作日志 |
| **teacher（教务）** | 教务人员 | 可以管理学生、教师、排课等教学相关功能 |
| **finance（财务）** | 财务人员 | 可以管理财务数据、缴费等财务相关功能 |
| **readonly（只读）** | 只读用户 | 只能查看数据，不能进行任何修改操作 |

### 创建新用户

只有管理员可以创建新用户：

1. 使用管理员账号登录
2. 访问"用户管理"页面（需要管理员权限）
3. 点击"新增用户"按钮
4. 填写用户信息：
   - 用户名（必填，唯一）
   - 密码（必填）
   - 角色（选择：admin/teacher/finance/readonly）
   - 真实姓名（可选）
5. 点击"保存"完成创建

## 功能模块说明

### 1. 学生管理

**功能位置**：首页 → 学生管理

**主要功能**：
- 添加学生信息
- 编辑学生信息
- 删除学生
- 查看学生列表
- 按状态筛选（在校/离校）
- 搜索学生

**操作说明**：

1. **添加学生**：
   - 点击"新增学生"按钮
   - 填写学生信息：
     - 姓名（必填）
     - 年级（必填）
     - 联系电话
     - 家长姓名
     - 在校状态（在校/离校）
   - 点击"保存"

2. **编辑学生**：
   - 在学生列表中点击"编辑"按钮
   - 修改学生信息
   - 点击"保存"

3. **删除学生**：
   - 点击"删除"按钮
   - 确认删除操作

**注意事项**：
- 删除学生前，请确保该学生没有关联的排课记录和缴费记录
- 建议将离校学生状态改为"离校"而不是删除，以保留历史数据

**操作说明**：

**注意事项**：

### 3. 课程管理

**功能位置**：首页 → 课程管理

**主要功能**：
- 添加课程配置
- 编辑课程信息（包括设置课程单价）
- 删除课程
- 查看课程列表

**操作说明**：

1. **添加课程**：
   - 点击"新增课程"按钮
   - 填写课程信息：
     - 课程名称（必填，如：数学1v1、数学1v2）
     - 科目（必填）
     - 单价（必填，用于计算收入）

2. **设置课程单价**：
   - 编辑课程信息
   - 修改"单价"字段
   - 单价用于计算学生缴费时的"学生单价"

**注意事项**：
- 课程单价会影响财务统计中的"当月收入"计算
- 禁用状态的课程不会在排课时显示

### 4. 排课管理

**功能位置**：首页 → 排课管理

**主要功能**：
- 为学生排课
- 查看周视图排课
- 修改课程状态（正常/请假/跑空）
- 删除排课
- 复制排课到下一周
- 切换到日历视图

**操作说明**：

1. **新增排课**：
   - 点击"新增排课"按钮
   - 选择学生、科目、教师、日期、时段、教室
   - 点击"保存"
   - **注意**：排课会自动减少学生的剩余课时

2. **查看排课**：
   - 使用月份选择器选择要查看的月份
   - 使用周选择器选择要查看的周
   - 点击"上一周"/"下一周"按钮切换周

3. **修改课程状态**：
   - 点击课程卡片
   - 选择状态：
     - **正常**：正常上课，计入课时
     - **请假（已排课）**：学生请假但已排课，不计入课时，减少1次剩余课时
     - **请假（未排课）**：学生请假且未排课，不计入课时，不减少剩余课时
     - **跑空**：老师未到，按0.5课时计算
   - 点击"保存"

4. **删除排课**：
   - 点击课程卡片的"删除"按钮
   - 确认删除
   - **注意**：删除排课会自动恢复1次剩余课时

5. **复制排课**：
   - **复制到下一周**：点击"复制到下一周"按钮，自动复制本周所有排课到下一周
   - **复制到指定周**：点击"复制到指定周"按钮，选择目标周进行复制

6. **切换视图**：
   - 点击"切换到星期模式"或"切换到周模式"按钮
   - 星期模式：按星期几显示排课
   - 周模式：按周显示排课

**注意事项**：
- 排课时系统会自动检查剩余课时，如果不足会提示
- 删除排课会恢复1次剩余课时
- 修改课程状态会影响"当月课时"的计算：
  - 正常 = 1课时
  - 请假（已排课）= -1课时（减少）
  - 请假（未排课）= 0课时
  - 跑空 = 0.5课时

### 6. 缴费管理

**功能位置**：首页 → 缴费管理

**主要功能**：
- 记录学生缴费
- 查看缴费历史
- 删除缴费记录
- 按月份、学生筛选缴费记录

**操作说明**：

1. **新增缴费**：
   - 点击"新增缴费"按钮
   - 填写缴费信息：
     - 缴费日期（必填）
     - 学生姓名（必填，从下拉列表选择）
     - 原始费用（必填）
     - 优惠力度（百分比，如：10表示10%优惠）
     - 报课节数（必填，会自动增加到剩余课时）
     - 备注（可选）
   - 点击"保存"
   - **系统自动计算**：
     - 缴纳费用 = 原始费用 × (1 - 优惠力度/100)
     - 学生单价 = 缴纳费用 / 报课节数
     - 剩余课时 += 报课节数

2. **查看缴费记录**：
   - 使用月份选择器筛选
   - 使用学生下拉列表筛选特定学生
   - 查看缴费详情和计算出的学生单价

3. **删除缴费**：
   - 点击"删除"按钮
   - 确认删除
   - **注意**：删除缴费会减少相应的剩余课时

**注意事项**：
- 缴费时输入的"报课节数"会自动增加到学生的剩余课时
- 系统会根据缴费金额和报课节数自动计算"学生单价"
- 学生单价用于财务统计中的"当月收入"计算

### 7. 学生课时

**功能位置**：首页 → 学生课时

**主要功能**：
- 查看学生课时统计
- 查看剩余课时
- 按月份查看历史数据

**课时说明**：

- **当月原始课时**：来自排课记录的次数（未修改状态时）
- **当月课时**：
  - 如果未修改课程状态，等于当月原始课时
  - 如果修改了课程状态：
    - 正常课程 = 1课时
    - 请假（已排课） = -1课时
    - 请假（未排课） = 0课时
    - 跑空 = 0.5课时
- **累计课时**：上月累计课时 + 当月课时
- **剩余课时**：
  - 每排1次课，减少1次剩余课时
  - 只能通过缴费增加

**操作说明**：

1. **查看课时统计**：
   - 选择要查看的月份
   - 查看所有学生的课时数据
   - 可以按学生姓名搜索

2. **查看剩余课时**：
   - 剩余课时显示在列表中
   - 如果剩余课时不足，系统会发送通知提醒

### 8. 老师课时

**功能位置**：首页 → 老师课时

**主要功能**：
- 查看每位老师每月的课时总数
- 用于计算老师成本

**操作说明**：

1. **查看老师课时**：
   - 选择要查看的月份

---

### 9. 财务统计

**功能位置**：首页 → 财务统计

**主要功能**：
- 查看收入统计
- 查看成本统计
- 查看利润统计
- 手动输入成本数据

**操作说明**：

1. **查看财务数据**：
   - 选择要查看的月份
   - 系统自动显示：
     - **当月收入**：自动计算（当月课耗 × 学生单价）
     - **老师成本**：自动计算（老师课时 × 每节课成本 + 老师底薪）
     - **营销成本**：需要手动输入（传单 + 人工）
     - **房租水电**：需要手动输入（房租 + 水电）
     - **其它成本**：需要手动输入（打印纸 + 打印粉）
     - **当月利润**：自动计算（收入 - 所有成本）

2. **输入成本数据**：
   - 点击"编辑"按钮
   - 输入各项成本：
     - 传单费用
     - 人工费用
     - 房租
     - 水电费
     - 打印纸费用
     - 打印粉费用
   - 点击"保存"
   - 系统会自动计算总成本和利润

**注意事项**：
- 收入数据来自学生课时统计和缴费记录
- 老师成本自动计算，无需手动输入
- 其他成本需要每月手动输入
- 利润 = 收入 - 所有成本

## 常见操作流程

### 流程一：新生入学流程

1. **添加学生信息**
   - 进入"学生管理"
   - 点击"新增学生"
   - 填写学生基本信息
   - 保存

2. **记录首次缴费**
   - 进入"缴费管理"
   - 点击"新增缴费"
   - 填写缴费信息（包括报课节数）
   - 保存（系统自动增加剩余课时）

3. **开始排课**
   - 进入"排课管理"
   - 为学生排课
   - 系统自动减少剩余课时

### 流程二：日常排课流程

1. **查看剩余课时**
   - 进入"学生课时"
   - 查看学生的剩余课时
   - 如果不足，提醒家长缴费

2. **排课**
   - 进入"排课管理"
   - 选择学生、教师、日期、时段
   - 保存排课

3. **课程结束后**
   - 如果学生请假或老师跑空，修改课程状态
   - 系统自动调整课时统计

### 流程三：月末财务统计流程

1. **确认排课数据**
   - 进入"排课管理"
   - 确认所有课程状态正确
   - 修改异常状态（请假、跑空等）

2. **查看课时统计**
   - 进入"学生课时"
   - 确认当月课时数据正确
   - 进入"老师课时"
   - 确认老师课时数据正确

3. **输入成本数据**
   - 进入"财务统计"
   - 点击"编辑"
   - 输入营销成本、房租水电、其它成本
   - 保存

4. **查看利润**
   - 系统自动计算当月利润
   - 查看收入、成本、利润报表

## 注意事项

### 1. 数据安全

- ⚠️ **定期备份数据库**：数据库文件位于项目目录下的 `jiaowu.db`
- ⚠️ **修改默认密码**：首次登录后立即修改管理员密码
- ⚠️ **权限管理**：只给用户分配必要的权限
- ⚠️ **操作日志**：定期查看操作日志，发现异常操作

### 2. 课时管理

- ⚠️ **剩余课时**：排课会自动减少剩余课时，请确保学生有足够的剩余课时
- ⚠️ **课程状态**：修改课程状态会影响课时计算，请谨慎操作
- ⚠️ **删除排课**：删除排课会恢复1次剩余课时，但不会恢复已消耗的课时

### 3. 财务统计

- ⚠️ **数据准确性**：财务统计依赖排课和缴费数据，请确保数据准确
- ⚠️ **成本输入**：营销成本、房租水电等需要每月手动输入
- ⚠️ **学生单价**：学生单价来自缴费记录，确保缴费时正确输入报课节数

### 4. 系统维护

- ⚠️ **定期更新**：定期更新系统依赖包
- ⚠️ **日志清理**：定期清理操作日志，避免数据库过大
- ⚠️ **性能优化**：如果数据量大，考虑定期归档历史数据

## 常见问题

### Q1: 忘记管理员密码怎么办？

**A**: 如果忘记管理员密码，可以通过以下方式重置：

1. 停止应用
2. 使用Python脚本重置密码：
```python
from app import create_app
from extensions import db
from models import User

app = create_app()
with app.app_context():
    user = User.query.filter_by(username='admin').first()
    if user:
        user.set_password('admin123')  # 设置新密码
        db.session.commit()
        print('密码已重置为: admin123')
```

3. 重新启动应用，使用新密码登录

### Q2: 排课时提示"剩余课时不足"怎么办？

**A**: 
1. 进入"学生课时"查看学生的剩余课时
2. 如果剩余课时不足，需要先记录缴费
3. 进入"缴费管理"，添加缴费记录，输入报课节数
4. 缴费后，剩余课时会自动增加
5. 然后可以继续排课

### Q3: 如何修改已排课程的状态？

**A**:
1. 进入"排课管理"
2. 找到要修改的课程
3. 点击课程卡片
4. 在弹出的编辑窗口中选择新的状态
5. 点击"保存"

### Q4: 财务统计中的"当月收入"为什么是0？

**A**: 可能的原因：
1. 该月没有排课记录
2. 学生没有缴费记录（学生单价无法计算）
3. 课程状态都是"请假"或"跑空"

解决方法：
1. 确认该月有正常的排课记录
2. 确认学生有缴费记录，且报课节数正确
3. 确认课程状态为"正常"

### Q5: 如何导出数据？

**A**: 
1. 大部分页面都支持导出功能
2. 点击页面上的"导出"按钮
3. 选择导出格式（Excel/CSV）
4. 下载导出的文件

### Q6: 系统运行缓慢怎么办？

**A**:
1. 检查数据库文件大小，如果过大考虑清理历史数据
2. 检查操作日志，定期清理旧日志
3. 重启应用
4. 检查服务器资源（CPU、内存）

### Q7: 如何备份数据？

**A**:
1. 停止应用
2. 复制数据库文件 `jiaowu.db` 到安全位置
3. 如果需要，也可以备份整个项目目录

### Q8: 如何恢复数据？

**A**:
1. 停止应用
2. 用备份的 `jiaowu.db` 文件替换当前的数据库文件
3. 重新启动应用

### Q9: 可以同时登录多个账号吗？

**A**: 
- 可以在不同的浏览器或浏览器标签页中登录不同的账号
- 但在同一个浏览器中，后登录的账号会覆盖前一个账号的登录状态

### Q10: 如何查看操作历史？

**A**:
1. 使用管理员账号登录
2. 访问"操作日志"页面
3. 可以按用户、时间、操作类型等条件筛选
4. 可以导出日志数据
