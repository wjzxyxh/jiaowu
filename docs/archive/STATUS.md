# 项目运行状态

## ✅ 前端已启动

前端开发服务器正在运行：
- **地址**: http://localhost:3000/
- **状态**: ✅ 运行中

## ⚠️ 下一步：启动后端

前端需要后端API才能正常工作。请在**另一个终端**启动后端：

```bash
# 方式1：使用启动脚本
./start_backend.sh

# 方式2：直接运行
python3 app.py
```

后端将在 http://localhost:5000 启动

## 📋 完整启动检查清单

- [x] Node.js 已安装
- [x] 前端依赖已安装 (`npm install`)
- [x] 前端服务器已启动 (http://localhost:3000)
- [ ] 后端服务器已启动 (http://localhost:5000)
- [ ] 可以访问登录页面

## 🌐 访问应用

启动后端后，访问：
- **前端**: http://localhost:3000
- **后端API**: http://localhost:5000/api

## ⚠️ 注意事项

1. **Vite CJS 警告**: 这是 Vite 5.x 的一个已知警告，不影响使用。可以忽略。

2. **网络访问**: 如果需要从其他机器访问，启动 Vite 时使用：
   ```bash
   npm run dev -- --host
   ```

3. **后端端口**: 确保后端运行在 5000 端口（前端代理配置的端口）

4. **CORS**: 后端已配置 CORS，允许前端跨域请求

## 🐛 常见问题

### 前端无法连接后端

1. 确认后端已启动：访问 http://localhost:5000/api/current-user
2. 检查端口是否正确（后端5000，前端3000）
3. 查看浏览器控制台的错误信息

### 登录后跳转问题

确保后端API返回正确的用户信息格式。
